# private_gpt_chabot_v1.0
🤖 Enterprise Local Document Assistant (RAG)
The Problem Companies lose countless hours searching for specific information buried within contracts, technical manuals, and financial reports. Furthermore, using public AI tools (like standard ChatGPT) poses significant security risks for confidential data.

The Solution This application is a 100% Local AI Assistant. It allows users to "chat" with their private PDF documents to extract precise information instantly.

🔒 Total Privacy: Data never leaves the client's local machine/server.

⚡ Semantic Search: Understands context, not just keywords.

✅ Zero API Costs: Powered by Open Source models (Llama 3 / Mistral) via Ollama.

Tech Stack

Python 3.10+

Frontend: Streamlit (Clean, interactive UI)

Orchestration: LangChain

Vector Store: ChromaDB (Local vector database)

LLM Engine: Ollama (Llama 3)
